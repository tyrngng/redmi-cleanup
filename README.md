# Redmi Cleanup

Программа очищает Xiaomi / Redmi / POCO на MIUI от рекламы, трекеров и предустановленного мусора и ускоряет телефон. Она работает через ADB с компьютера, как [cleanyourtv](https://github.com/gathin23/cleanyourtv) для телевизоров. Делалась под **Redmi 10A**, но подходит для любого телефона на MIUI.

- Root не нужен, загрузчик разблокировать не нужно, гарантия сохраняется.
- Удаление можно отменить: приложения удаляются только для пользователя (`pm uninstall --user 0`), а APK остаются в системе. Любое приложение можно вернуть пунктом меню «Восстановить» без сброса.
- Системные пакеты, удаление которых ломает телефон (лаунчер, Безопасность, SystemUI, сервисы Google, Play Маркет и т. д.), стоят в списке защиты. Программа их не тронет.

## Что делает

| Пункт | Что происходит |
|---|---|
| **Автоочистка** | Удаляет ~70 пакетов: рекламу MIUI (MSA, MAB), аналитику и телеметрию, App Vault, «карусель обоев», GetApps, Mi Music/Video, предустановки Facebook/Netflix/Amazon/TikTok и т. п., китайские сервисы, лишние приложения Google. Затем выполняет ускорение |
| **Ускорение** | Ставит анимации 0.5x, чистит кэш, закрывает фоновые процессы и **перекомпилирует приложения** (`bg-dexopt-job`). Перекомпиляция больше всего помогает телефону, который тормозит с покупки |
| **Необязательные** | Сначала показывает список (Mi Cloud, ShareMe, Погода, Заметки, YouTube, Gmail, Ассистент и т. д.), потом удаляет то, что вы выберете |
| **Блокировка рекламы DNS** | Включает «Частный DNS» AdGuard. Он режет рекламу и трекеры во всех приложениях и браузерах |
| **Восстановить** | Возвращает удалённые приложения: из журнала `removed_packages.txt` или по имени пакета |

Mi Browser удаляется, только если на телефоне есть Chrome. Клавиатура Facemoji удаляется, только если есть Gboard. Так телефон не останется без браузера или клавиатуры.

## Как запустить

### 1. Подготовьте телефон
1. **Настройки → О телефоне** → нажмите 7 раз на **«Версия MIUI»**.
2. **Настройки → Расширенные настройки → Для разработчиков**, включите:
   - **Отладка по USB**
   - **Установка через USB**
   - **Отладка по USB (настройки безопасности)**. Без этого пункта не заработают ускорение анимаций и DNS. MIUI для него просит вставить SIM-карту и войти в Mi-аккаунт. Если не получится, удаление мусора всё равно будет работать.
3. Подключите телефон кабелем. В уведомлении USB выберите **«Передача файлов»**.
4. Когда появится окно **«Разрешить отладку по USB?»**, отметьте «Всегда» и нажмите **«Разрешить»**.

### 2. Запустите программу
Нужен [Python 3](https://www.python.org/downloads/). При установке на Windows отметьте **«Add python.exe to PATH»**. Если ADB не установлен, программа сама скачает его с сайта Google.

- **Windows:** дважды щёлкните `START.bat`
- **Linux / macOS:** `./start.sh`

Без кабеля, по Wi-Fi: запустите `START-WIFI.bat` (или `./start.sh --wifi`). Подробнее в разделе ниже.

Откроется меню. Для основной очистки выберите **1 — Автоочистка**. После очистки программа предложит перезагрузить телефон.

Режим без меню: `python redmi_cleanup.py --auto` (с ключом `--yes` вопросы не задаются).

## Подключение по Wi-Fi (без кабеля)

Работает на Android 11 и новее, Redmi 10A подходит. Телефон и компьютер должны быть подключены к **одной сети Wi-Fi**. Через интернет из другой сети подключиться нельзя, и это сделано специально: открытый порт отладки дал бы полный доступ к телефону кому угодно.

1. На телефоне откройте **Для разработчиков** и включите **«Беспроводная отладка»**. Затем нажмите на сам пункт.
2. Запустите `START-WIFI.bat`.
3. На телефоне нажмите **«Подключение устройства с помощью кода подключения»**. Введите в программу адрес из этого окна (например `192.168.1.5:37000`) и код из 6 цифр.
4. Закройте окно с кодом. Введите в программу **«IP-адрес и порт»** с экрана «Беспроводная отладка», у него другой порт.

Сопряжение делается один раз. В следующий раз пропустите шаг 3, нажав Enter, и введите только IP-адрес и порт. Порт меняется при каждом включении беспроводной отладки.

Пока идёт оптимизация приложений, телефон должен оставаться в Wi-Fi и не уходить в сон. Лучше поставить его на зарядку. Когда закончите, выключите «Беспроводную отладку».

## Если что-то пропало

Запустите программу и выберите **7 — Восстановить**. Можно вернуть приложение и вручную:

```
adb shell cmd package install-existing com.miui.weather2
```

Сброс до заводских настроек тоже возвращает все удалённые приложения.


Программа удаляет только то, что считается безопасным, и любое изменение можно отменить. Но прошивки MIUI отличаются от модели к модели и от версии к версии, поэтому вы используете программу на свой страх и риск. Если после очистки что-то работает не так, верните приложение пунктом «Восстановить» и [создайте issue](https://github.com/tyrngng/redmi-cleanup/issues). В issue укажите модель телефона, версию MIUI и имя пакета.

## Свой список

Списки пакетов лежат в начале файла `redmi_cleanup.py`: `RECOMMENDED`, `OPTIONAL` и `PROTECTED`. Пакеты добавляются и удаляются в формате `("имя.пакета", "описание")`. Pull request'ы с проверенными пакетами для других моделей приветствуются.
